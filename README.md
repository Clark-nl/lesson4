# lesson4

## 💡 아이디어 수익화 플랫폼

자동화 및 아이디어 매출 창출을 위한 간단한 웹 앱입니다. `index.html`을 브라우저에서 열면 바로 사용할 수 있으며, 별도 서버나 빌드 과정이 필요 없습니다.

### 기능
- 아이디어 등록 (제목, 설명, 카테고리, 예상 매출 잠재력, 구현 난이도, 자동화 적합도)
- 입력값을 기반으로 우선순위 점수 자동 계산
- 칸반 보드로 단계 관리: 아이디어 → 검증중 → 개발중 → 출시 → 수익창출중 (드래그 앤 드롭)
- 점수순/최신순 정렬, 카테고리 필터
- 대시보드: 전체 아이디어 수, 평균 우선순위 점수, 수익창출중 개수, 최고 점수 아이디어
- 브라우저 `localStorage`에 자동 저장

### 실행 방법
`index.html` 파일을 브라우저로 열기만 하면 됩니다.
