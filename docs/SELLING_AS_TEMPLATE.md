# "Focus & Tabs"를 보일러플레이트 템플릿으로 판매하기

`extension/` 코드베이스 자체를 **"프리미엄 결제가 내장된 크롬 익스텐션 스타터 템플릿"**으로 다른 개발자에게 판매하는 아이디어(#3)의 실행 가이드입니다. 실제 사용자에게 파는 "Focus & Tabs" 익스텐션(#2)과는 별개의 상품입니다 — 같은 코드, 다른 고객.

## 타겟 고객

- 크롬 익스텐션 아이디어는 있지만 결제/라이선스 로직부터 짜기 귀찮은 1인 개발자
- "이번 주말에 사이드 프로젝트 하나 출시하고 싶다"는 인디해커
- 포트폴리오용으로 완성도 있는 MV3 예제가 필요한 주니어 개발자

## 왜 이 코드베이스가 템플릿으로 팔릴 만한가

일반 "Hello World" 익스텐션 보일러플레이트와 다르게, 이미 다음이 동작하는 상태로 들어 있습니다:

- Manifest V3 서비스 워커 + 알람 기반 타이머 패턴 (1초 폴링 없이 정확한 타이밍)
- `chrome.storage.sync` / `local` 분리 전략 (라이선스는 sync, 세션 상태는 local)
- Gumroad License Verification API 연동이 실제로 붙어 있는 프리미엄 게이팅 (`lib/premium.js`)
- 라이트/다크 테마 대응 팝업·옵션 UI
- 무료/프리미엄 기능 분기 UI 패턴 (잠금 아이콘, 업그레이드 유도 카피)

즉 구매자는 "결제 붙은 크롬 익스텐션"의 뼈대를 그대로 가져다 자기 기능으로 갈아끼우기만 하면 됩니다.

## 패키징 방법

1. `extension/` 폴더를 복사해 실제 상품과 분리된 배포용 zip 생성 (`focus-and-tabs-starter-template.zip`).
2. `lib/premium.js`의 `GUMROAD_PRODUCT_PERMALINK`를 `"YOUR_GUMROAD_PRODUCT_PERMALINK"` placeholder 그대로 두고, README에 "본인 상품 permalink로 교체하세요" 안내를 강조.
3. `extension/README.md`를 구매자 대상 `SETUP.md`로 이름 바꿔 zip 최상단에 포함 (설치 → 커스터마이징 → Gumroad 연동 → 웹스토어 배포까지 5분 안에 따라할 수 있게).
4. 라이선스 고지 추가: 구매자는 이 코드를 기반으로 자신의 상품을 만들어 판매할 수 있지만, 코드 자체를 "템플릿"으로 재판매하는 것은 금지 (표준 Regular License 문구, 아래 참고).

### 템플릿 이용 라이선스 문구 (초안)

> 본 템플릿은 1개 최종 프로덕트에 사용할 수 있는 라이선스로 판매됩니다. 구매자는 이 코드를 기반으로 자신의 크롬 익스텐션을 개발·배포·판매할 수 있습니다. 단, 코드 자체를 템플릿/보일러플레이트로 재판매하거나 무료 배포하는 것은 금지됩니다.
